说明与判定方法

本页用 @thib3113/web-bluetooth-dfu 库 (来自 npm, 已被广泛使用) 传输固件。它内部自带 GATT 互斥队列、PRN 流控、CRC 校验、Smart Speed 降速。它的行为与你手写的 ota.js 完全独立, 因此结果可作为「第三方基准」。

判定表:

· 库 成功 + ota.js 失败 → 你的 ota.js 时序/流控实现有问题, 需对照库逻辑修。

· 库 也在同一对象边界断连 → 固件或硬件/射频环境问题 (与网页无关), 需查固件 EXECUTE/擦除/监督超时。

· 库 PRN=0 快发失败但 PRN=1 慢发成功 → 固件缓冲不足 (balloc 17), 需网页节流, 这是预期内的固件约束。

注意: 本页需通过 http(s) 打开 (如 python3 -m http.server), 且浏览器需开启 Web Bluetooth。
